# Better Canvas


## Problem
Canvas Instructure UI/UX sucks. How my school uses it sucks even more.

Our Program is a course and each of the lessons materials etc are modules. 

The UI of canvas instructure is ugly. It takes ages to navigate to modules and
the rendering of those pages is ugly. Especially code example rendering. 

## Solution

Our next course is about VUE so using vue here instead of react. 

Create an site that connects to users via API. Should have no backend. Also
settings and decisions stored in local storage. API key ideally encrypted or
somehow on vercel or so via server function or similar if possible. 

On first connect I can select courses to show (there are some sort of admin
material courses that I do not want to show)

Then start page should be upcoming assignments. And modules. Somehow also
sortable or the ones from old courses should be able to be closed but still be
available under a previous lectures route. 

General UI is inspired by Obisidan reader extension esp text rendering and
layout. 

In line code rendering example should be able to set syntax theme and look nice. 

The whole thing should be nice to actually read and use as a study tool. A
pleasure. Canvas is not.
